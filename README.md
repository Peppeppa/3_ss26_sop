# System-oriented Programming (SOP) – THWS

Studienmaterial zu **System-oriented Programming** bei Prof. Dr. Peter Braun (THWS). Der Kurs behandelt Linux, Bash, Git, C, Speicherverwaltung, Build-Systeme, Synchronisierung und die Linux-API.

## Wissensbasis

- [INDEX.md](INDEX.md): 17 Skripte, 451 physische PDF-Seiten, Metadaten, Themenfundstellen und Prüfsummen
- [EXERCISES.md](EXERCISES.md): Aufgabenübersicht und Fundstellen ohne Lösungsspoiler
- [sources/](sources/): Originalsprachige, seitenweise aus den PDFs extrahierte Skripttexte
- [PROJECT.md](PROJECT.md): Repo-Konfiguration, zentrale Skills und Importgrenzen
- `userinfo.sh`: bereits bestehende Datei aus dem Repository; unverändert erhalten
